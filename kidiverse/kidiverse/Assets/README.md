## Where to Add
1. Open `Assets.xcassets` in Xcode
2. Drag and drop images into the asset catalog
3. Create image sets with the exact names listed above
4. Set appropriate sizes (tvOS 1x and 2x)

## Note
The app will work without images - emojis are used as fallbacks throughout the app.
